# kamahdi

## ETHIX mobile prototype

`ethix-prototype/` holds the 13 artboards of the ETHIX mobile app prototype (Design Component `.dc.html` files plus `canvas.json`), built on the ETHIX Design System.

Screens: Home, Invest, Sending securely, Investment successful, Portfolio, Settings, Sign-up, Card management, ETHIX Home, ETHIX Give, Transfer, Activity, Notifications.
